\# Go Nuxt Recruitment Lab



Project latihan sistem rekrutmen menggunakan Go, Nuxt, dan PostgreSQL.



\## Tujuan

Belajar alur aplikasi recruitment dengan pendekatan Clean Architecture.



\## Modul awal

\- Lowongan

\- Pelamar

\- Seleksi administrasi

\- Jadwal wawancara

\- Penilaian

\- Pengumuman



\## Stack

\- Backend: Go

\- Frontend: Nuxt

\- Database: PostgreSQL
